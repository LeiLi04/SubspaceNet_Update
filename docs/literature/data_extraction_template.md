# 数据抽取表单（Data Extraction Template）

建议每篇纳入文献一行，便于后续按主题综合；可直接复制到表格软件或 Markdown 表格。

---

## 1. 字段说明（建议最小集合）
- `Paper ID`: 自定义编号（如 A01, B12）
- `Citation`: 作者-年份-标题（或 BibTeX key）
- `Venue`: 期刊/会议/预印本
- `Task`: DOA/AoA（静态/动态/跟踪）
- `Array/Signal`: ULA/UCA；窄带/宽带；快拍数；源数（固定/可变）
- `Method Family`: Classical / Deep / Model-based DL / Adaptation / Tracking-coupled
- `Key Idea`: 1-2 句总结
- `Supervision`: supervised / unsupervised / self-supervised / semi-supervised
- `Shift/Mismatch`: 漂移/失配类型（间距误差、相位偏差、互耦、几何噪声、多径等）
- `Downstream`: KF/EKF/UKF/particle；是否使用 innovation/residual
- `Adaptation Trigger`: 阈值/统计检验/不确定性/固定周期/无触发
- `Adaptation Loss`: MSIE/重建/代理谱/一致性约束等
- `Baselines`: MUSIC/ESPRIT/Root-MUSIC/SubspaceNet/其它
- `Metrics`: RMSPE/RMAPE/MAE/CRB/innovation stats/track RMSE 等
- `Main Result`: 最关键的数值结论（提升幅度、鲁棒性）
- `Reproducibility`: code/data 是否公开；关键超参是否给出
- `Inclusion`: Included / Background / Excluded（基于 full-text screening 口径）
- `Quality/Evidence`: 质量等级 + 关键证据来源（Table/Fig/实验/仿真；必要时注明 OCR）
- `Notes`: 与本仓库对齐点/可复现要点
