# Review Output Templates

## Template A: Full Review

```markdown
## 1. Summary
[2-5 sentences describing problem, method, and claimed contributions]

## 2. Strengths
- [Strength 1]
- [Strength 2]

## 3. Major Concerns
- [Concern]: [Evidence in paper] -> [Required revision]

## 4. Minor Concerns
- [Minor issue 1]
- [Minor issue 2]

## 5. Reproducibility And Ethics
- Reproducibility: [High/Medium/Low] with reason
- Ethics: [No major issue / Needs clarification / Serious issue] with reason

## 6. Scores (1-5)
- Novelty: [ ]
- Technical Soundness: [ ]
- Experimental Rigor: [ ]
- Clarity: [ ]
- Reproducibility: [ ]

## 7. Recommendation
- Decision: [Strong Accept / Weak Accept / Weak Reject / Strong Reject]
- Confidence: [High / Medium / Low]
- Rationale: [short justification]
```

## Template B: Rebuttal-Aware Update

```markdown
## Updated Assessment After Rebuttal

### Issues Resolved
- [Issue] -> [How rebuttal addressed it]

### Issues Remaining
- [Issue] -> [Why still unresolved]

### Final Recommendation Update
- Previous: [ ]
- New: [ ]
- Reason for change/no change: [ ]
```
