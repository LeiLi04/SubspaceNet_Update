# Off-Grid DOA Estimation via a Deep Learning Framework

**Authors:** Huang, Yan; Zhang, Yanjun; Tao, Jun; Wen, Cai; Liao, Guisheng; Hong, Wei
**Venue:** Science China Information Sciences, Vol 66(12), 2023
**Zotero Key:** MSMVFNTT
**Category:** Methods

---

## Research Question
How can deep learning address the grid mismatch problem in sparse recovery-based DOA estimation?

## Core Method
- Deep learning framework for off-grid DOA estimation
- Addresses the fundamental grid mismatch issue where true DOAs don't align with predefined grid points
- Learns continuous DOA mapping rather than grid-based classification

## Key Findings
- Overcomes grid mismatch limitations of conventional sparse recovery methods
- Achieves off-grid DOA estimation without explicit grid refinement procedures
- Demonstrates advantages over on-grid DL approaches

## Limitations
- Published in regional venue (Science China)
- Grid-free approaches like SubspaceNet's subspace decomposition inherently avoid this problem

## Relevance to Our Research
Addresses grid mismatch — a problem that SubspaceNet avoids entirely through subspace decomposition and root-finding. Highlights an advantage of the subspace-based approach over sparse recovery approaches.
